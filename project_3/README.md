# Defensive Strategy Analysis against Real Madrid

For the third project of the Soccermatics Pro course we were given SkillCorner data for all of Real Madrid's matches for the 2024/25 and 2025/26 La Liga and Champions League seasons. This directory contains the final presentation PDF, notebooks which contain the analysis code and code that generated the plots, and code for a Streamlit app that visualizes interactive charts of the same plots and heatmaps in the presentation.

Streamlit app URL:
https://defense-viz-app-soccermaticspro.streamlit.app/
